# 橘中学校 生徒会プラットフォーム — UIリデザイン版

## 構成
- index.html: Home
- newsroom.html: Newsroom
- events.html: Events（ダーク・シネマティックデザイン）
- progress.html: Progress
- petitions.html: Petitions
- feedback.html: Feedback
- school-rules.html: School Rules
- site.css / site.js: 共通デザイン・ナビゲーション

## 公開
Cloudflare PagesでGitHubリポジトリと接続し、ビルドコマンドなし、出力ディレクトリをプロジェクトのルートに設定します。

## 注意
このZIPはUIを中心とした静的フロントエンドです。ログイン、本人確認、オンライン署名、意見送信、管理画面、時間帯アクセス制限などのバックエンド機能は実装していません。学校の承認と運用体制が整うまでは個人情報を収集せず、正式な校則本文や未承認情報を掲載しないでください。
